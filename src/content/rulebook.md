## 第零章 · 文档说明

### 0.1 这是什么样的游戏

这是一款 **纯语言角色扮演游戏（Text-based Roleplay）**。没有骰子、没有数值计算器，只有你、世界模拟系统，以及六面世界本身。

- **玩家**：用自然语言描述角色的行动、言语、意图与内心。
- **世界模拟系统（AI）**：维护世界状态、推进时间、结算后果、扮演所有 NPC。
- **规则文档（本文）**：定义世界的边界、成长逻辑、历史约束与系统行为准则。

### 0.2 核心定位

**核心体验**：玩家不是被选中的天命之子。玩家只是六面世界中出生的一个人。

你可以是阿斯拉王国的贵族子弟、布耶纳村的农家孩子、魔大陆的魔族后裔、米里斯神圣国的教徒、拉诺亚魔法大学的学生、冒险者公会的 F 级新人、剑之圣地的学徒，甚至是转生者。**也可以一辈子不离开出生的村庄。这同样是一种完整人生。**

**情感核心**：每个人物都会爱、会恨、会嫉妒、会牺牲、会背叛、会后悔、会怀念。你的父亲可能死于迷宫中的九头龙。你的母亲可能被转移事件带到世界另一端。你的爱人可能被人神使徒引向歧途。你会在某个深夜想起布耶纳村的麦田、魔法大学图书馆的烛光、第一次挥剑时师父的呵斥。

**深度解析**：无职转生核心驱动力是「转生＋成长＋选择＋命运＋人神＋龙神＋家族＋悔恨」八位一体。人神在暗处拨弄棋局。龙神在轮回中寻找胜机。你面对的不仅是种族歧视、贵族政治、迷宫凶险、拉普拉斯的阴影——还有前世记忆的负担，灵魂中潜伏的软弱。**但选择比出身更重要。悔恨可以转化为力量。爱可以成为救赎。**

### 0.3 三方约定

| 角色 | 负责 | 不负责 |
| --- | --- | --- |
| 玩家 | 自己的人生、每一次选择、每一次情感 | 世界如何运转、NPC 如何抉择 |
| 世界模拟系统 | 维护六面世界状态、推进时间、结算因果、扮演所有 NPC | 剥夺玩家的行动自由 |
| 本规则书 | 约束世界的物理、历史、成长与系统行为 | 剧情走向、结局好坏 |

## 第一章 · 世界第一原则

> **世界不围绕玩家存在。**

你不是历史主角，不是预言中的救世主。六面世界存在人神、龙神奥尔斯帝德、七大列强、拉普拉斯、甲龙王佩尔基乌斯。他们都拥有自己的生命、目标与历史。世界在玩家出生前已运转数万年。你死后，六面世界仍将继续。

### 1.1 命运存在，但命运不围绕你旋转

人神的棋局在你出生前已展开。奥尔斯帝德的轮回在你祖父年轻时已进行过无数次。你不会因为「需要」而遇到人神，也不会因为「是主角」而获得龙神的指引。

### 1.2 人神确实存在

但人神不是为你存在的。人神透过未来视筛选使徒，在梦中低语，用话术诱导。他无法强制任何人——只能利用对方的欲望、恐惧、悔恨来编织陷阱。**人神不会逼迫你，他只会「建议」。**

### 1.3 转生确实存在

但转生不是你的特权。七星静香和秋人是被召唤来的。鲁迪乌斯是转生的。但这个世界绝大多数人只是普通出生、普通死亡。如果你恰好是转生者，前世记忆可能是一种优势，也可能是一种诅咒。

## 第二章 · 历史优先级别

### 2.1 优先级顺序

```
原著正史  ＞  时代设定  ＞  传奇人物  ＞  历史事件  ＞  玩家自由发挥
```

玩家不得取代原著主角，不得直接获得历史独有机缘。不得改变既成重大历史节点，除非玩家通过符合时代逻辑的行动与足够分量，产生足以扰动世界线的后果。

### 2.2 历史人物拥有独立命运

保罗·格雷拉特会在拯救塞妮丝的迷宫战役中死去。洛琪希会在甲龙历 424 年至 427 年间被人神设计感染魔石病而死。基斯会成为人神的暗子。奥尔斯帝德会在轮回中孤独前行。

这两条死亡各有一个前提，前提不成立时不会发生。保罗之死的前提是玩家真的跟着队伍下到转移迷宫最底层、参与了那场决战；洛琪希之死的前提是玩家做过人神使徒，也就是接受过它的「建议」，知情或不知情都算。前提不成立时，他们活着走下那件事——代价照旧，只是不必是死。

### 2.3 重大事件默认按时代推进

玩家可以在菲托亚领转移事件中幸存，但无法阻止转移的发生。玩家可以与人神使徒交锋，但无法轻松击败人神。

### 2.4 时间线锚点与可扰动区域

| 类别 | 内容 |
| --- | --- |
| **不可改变（锚点）** | 菲托亚领转移事件的发生、拉普拉斯的复活、鲁迪乌斯与三位妻子的婚姻 |
| **带前提的锚点** | 保罗的死亡（前提：玩家下到转移迷宫最底层并参与决战）、洛琪希的死亡（前提：玩家做过人神使徒） |
| **可被影响（缝隙）** | 死亡的具体方式和场景、转移事件中幸存者的命运、拉普拉斯复活后的行动路径、玩家身边 NPC 的生死、玩家自身在历史洪流中的位置和影响力 |

> **时间线修正法则**：玩家在「锚点」之间的「缝隙」中拥有自由行动的空间。微小改变会在几十年后产生蝴蝶效应。

## 第四章 · 地理详述

人之世界由 **中央大陆、魔大陆、米里斯大陆、贝卡利特大陆、天大陆与林古斯海** 组成。原本是彼此相连的巨大陆，在第二次人魔大战末期被魔力轰击形成林古斯海。

| 地区 | 说明 |
| --- | --- |
| **中央大陆** | 最大大陆。赤龙山脉把中央大陆分割成西、北、南部，山顶栖息着 S 级强度的赤龙。龙鸣山是世界上最高的灵山，其中的龙神孔迷宫与「地狱」和「魔神窟」齐名。 |
| **阿斯拉王国** | 人族最古老政权，世界第一大国。王都亚尔斯是首都。菲托亚领位于东北部，由伯雷亚斯家统治，首府罗亚，甲龙历 417 年因转移事件消失。 |
| **魔大陆** | 大部分被沙漠覆盖。分布着许多古代迷宫。魔族居住于此。 |
| **米里斯大陆** | 米里斯神圣国所在。世界第二大国。 |
| **贝卡利特大陆** | 迷宫圣地。大部分被沙漠覆盖，地下有大量迷宫。 |
| **天大陆** | 天族掌控高地。因甲龙王佩尔基乌斯的关系，与人族保持一定联系。 |

### 4.1 所在地与迁居

你的一生总得落在某一处地方。十二个去处写在这里，每一个都有自己的活法、自己的门槛，以及自己的时间点事件。

| 去处 | 门槛 | 原著里的位置 |
| --- | --- | --- |
| 布耶纳村 | 起点 | 菲托亚领的农业村庄。甲龙历 417 年以前，这里的日子只有麦子和牲口。 |
| 罗亚町 | 起点 | 菲托亚领首府，伯雷亚斯家的居城。 |
| 王都亚尔斯 | 贵族出身，或声望 / 魅力到一定分量 | 阿斯拉王国的中心，三个王位派系在此角力。 |
| 魔法都市夏利亚 | 魔术造诣，或大学出身，或经历过转移事件 | 拉诺亚魔法大学与魔术公会所在地。 |
| 米里希昂 | 米里斯信仰，或信仰 / 声望到一定分量 | 政教合一的神圣国首都。 |
| 米格路德族之村 | 魔族出身，或经历过转移事件，或名声足够大 | 洛琪希的故乡，魔大陆的沙海边。 |
| 迷宫都市拉潘 | 冒险者等级 D 以上，或声望足够，或经历过转移事件 | 贝卡利特大陆的迷宫都市。 |
| 西隆王国 | 西隆出身，或声望 / 密谋到一定分量 | 王龙王国的属国，国王帕克斯。 |
| 拉诺亚王都 | 智力 / 魔力 / 声望到一定分量 | 国王与魔术公会共治的魔法三大国之一。 |
| 剑之圣地 | 剑神流出身，或剑术造诣到一定分量 | 剑神流总本山。 |
| 天空之城 | 声望极高，或归顺龙神，或吹响过龙王之笛 | 甲龙王的浮空城。 |
| 龙鸣山 | 归顺龙神，或剑术与魔力都到顶峰 | 龙神孔迷宫所在，S 级赤龙的地盘。 |

**迁居**是换地方唯一的办法。走一趟要花掉整整一个月，因此一次就用尽当月的全部行动。
门槛不到，走不过去——一个布耶纳村的农家孩子不可能直接住进王都的贵族圈。

**人也是有所在地的。** 你在哪儿认识一个人，他就在哪儿。你搬走了，他还留在原地：
关系网里会写明「人在布耶纳村」，与他说话、帮他一把这些当面的事全部灰掉，他也再不会主动来找你。
想再见到他们，就得走回去。

**带谁走，是你自己定的。** 关系网里点开一个人，看板上有一个开关：**带着他一起走**。
开了，他往后跟你走到哪儿都能开口，条目上标着「与你随行」；关掉，他就留在此刻这个地方。
配偶与子女属于你的家，本来就在你身边，这条没有开关。
身份里带「旅伴／同行／随行／追随／同袍／战友」的人默认就是路上结的伴，你可以关掉他。
去问这件事本身得当面说——人不在跟前，问不出口。

**身边得有人，才谈得上陪家人。** 「陪家人过完一个月」「和家里坐下来谈一次」这类指令要身边真有能当面说上话的人才成立。
搬到一个谁都不认得的地方，这两条就灰了，按钮上写着缺什么——你总得先认识人。

所在地决定你能做什么：每个去处都有自己的行动，别处没有。它也决定**你会遇上什么**：
每一个去处都有一批只在特定年份等在那儿的事件。人在别处，那件事照样发生，只是与你无关。

**场合也跟着所在地走。** 集市与铺子只在有街市的地方开张，冒险者公会只在设了分部的城镇接委托，
拉诺亚魔法大学与书库在夏利亚，剑之道场在剑神流的总本山，王都贵族圈在阿斯拉的王都，
教会与神殿的根在米里希昂，迷宫与野外要往贝卡利特与魔大陆去，暗巷藏在大得能藏住人的城里，
佣兵营地与边境在有兵有仗的地方。人不在那儿，那一格就不该出现。

**剑有三处可练，深浅不同。** 剑之圣地的剑之道场是总本山，那里才有师范、有同门、有剑神的试炼。
罗亚町有一间旧道场，教头是退了役的冒险者，教的是最实用的那几手，练到斗气为止。
王都亚尔斯有近卫与贵族子弟共用的演武场，教习打过仗，比总本山浅、比镇上深，在那里练久了会被人看见。

## 第十一章 · 魔术体系与剑术流派

### 11.1 魔术体系

- **魔术阶级（七级）**：初级、中级、上级、圣级、王级、帝级、神级。
- **魔术分类**：攻击魔术、召唤魔术、治癒魔术、解毒魔术、结界魔术。
- **魔术属性**：火、水、风、土、雷、冰、重力、时间等。
- **发动方式**：分为咏唱和魔法阵两种，只有极少数人能无咏唱发动魔术。法阵类似用键盘录入编程，咏唱类似语音录入，无咏唱类似脑机录入。
- **无咏唱施法**：鲁迪乌斯在魔术大学期间就掌握了无咏唱施法。无咏唱魔术至少需要 100 米以上距离才能对标王级帝级战士。
- **魔术师的弱点**：顶级魔术师在近身战斗中弱势。

**魔术阶级晋升条件**

| 阶段 | 条件 |
| --- | --- |
| 初级 → 中级 | 掌握至少 3 种基础属性魔术。 |
| 中级 → 上级 | 达到四万分之一的比例，能够无咏唱施法。 |

### 11.2 剑术流派

| 流派 | 特征 |
| --- | --- |
| 剑神流 | 最流行的流派。以速度快闻名，主动进攻流派，招牌是「光之太刀」，同级基本无敌。 |
| 水神流 | 以反击和防御为核心。理论上同级无敌的其实是水神流，但修炼是三大流派中最难的。 |
| 北神流 | 融合了剑神流和水神流的特点。尤其是北二创造的奇拔派，动用一切可以动用的道具、魔术、装备来获取胜利。 |

- **剑术阶级（七级）**：初级、中级、上级、圣级、王级、帝级、神级。中级是一般骑士水平，上级为缠绕斗气的实力者，圣级为天才，王级以上为世界有数的实力者。

**剑术阶级晋升条件**

| 阶段 | 条件 |

| 圣级 → 王级 | 由本部道场的剑神亲自判定。 |
| 王级 → 帝级 | 本部道场的剑神判定。帝级为最上位、怪物级。 |
| 帝级 → 神级 | 最高位、最强级别。 |

### 13.1 升级条件

| 阶段 | 条件 |
| --- | --- |
| F → E | F 级工作 10 次 ＋ E 级工作 5 次连续 |

### 13.2 降级条件

比自己低级的委托连续失败 5 次降级；同级的委托连续失败 10 次降级；比自己高级的委托失败不降级，但连续失败 5 次后无法再接取该级别委托。

### 13.3 冒险者公约

- 未能达成委托，必须支付报酬的两成作为违约金。期限半年，无法支付将剥夺冒险者资格。
- 禁止违反各国法律、妨碍其他冒险者、私下买卖委托。
- 冒险者卡片遗失或退出公会后重新登录，层级将从 F 重新开始。
- 遇上魔物来袭等状况并由国家提出协助要求时，冒险者有义务遵守。

### 13.4 迷宫与职业

- **迷宫**：贝卡利特大陆是迷宫圣地。迷宫中有古代遗物、魔力付与品、稀有材料。

## 第二十九章 · 世界级事件与月度演化

**极少发生**：菲托亚领转移事件、拉普拉斯复活、第二次拉普拉斯战役、人神决战。

每个回合通常为**一个月**，系统自动结算：

```text
【第 N 回合 · 甲龙历 XXXX 年 XX 月 · 世界动态】
阿斯拉王国：……
拉诺亚王国：……
米里斯教团：……
魔法大学：……
冒险者公会：……
魔大陆：……
七大列强：……
人神：……
你所在地区：……
你能够获知的传闻：……
```

> 世界继续向前。玩家不参与，世界照样发展。

**行动次数**：一个月内能做的事有限。安逸难度每月 5 次行动，标准 4 次，残酷 3 次，地狱 2 次。次数用完就只能推进时间，靠反复休息刷状态是不成立的；精力与行动次数共同构成每月的边界。

**推演方式**：本作默认由本地引擎按固定规则推演世界动态与行动后果。你也可以在「AI 推演设置」里接入任意 OpenAI 兼容接口（含本地推理服务），此时世界动态、行动结算、临时抉择事件与死亡终章都改由大模型即时生成；接口不可用时会自动回退到本地引擎，人生不会中断。

模型有相当的叙事自由：它可以创造有名有姓的小人物与地点，让他们在后面的月份里再次出现；可以把新认识的人写进关系面板，把被注意到的变化写进系统记录，把人神或龙神的接触写进线索面板；可以判定玩家的行动彻底失败，也可以判定这次行动根本不费力气。抉择事件的出现间隔按难度控制（安逸约 4 回合一次，标准约 3 回合，残酷与地狱约 2 回合），但事件内容、选项与代价由模型根据剧情自行决定。

数值始终由引擎校验后落账，分两档额度：

| 通道 | 属性 | 阶级成长 | 目标进度 | 寿命 | 精力 | 关系好感 |
| --- | --- | --- | --- | --- | --- | --- |
| 普通行动 / 每月世界动态 | ±15 | 0–20 | ±8 | ±2 | ±40 | ±3 |
| 抉择事件（特殊事件） | ±45 | 0–60 | ±24 | ±6 | ±120 | ±9 |

抉择事件的额度是常规的三倍，是留给真正罕见的时刻的：继承遗产、被判重刑、失去至亲、被诅咒缠身、捡到圣物、身份暴露、与列强正面交手。绝大多数抉择仍然只需要几点到十几点的变化，只有选项本身足够重大时才动用大额度，而且代价与收益对称。

模型可以决定「发生了什么」，但不能绕过这两档边界直接改写你的档。如果你希望一次普通行动也能造成剧变，那件事会被安排成下个月的抉择事件，而不是塞进日常结算里。

**交给模型的判断**：除了叙述与数值，模型还可以决定角色的生死（它可以判定这个月或这次行动就要了你的命，并自己写死因；引擎只负责执行死亡、终章与成就结算）、改变各方势力对你的态度（势力面板会随之变动），以及写出被记进存档的「自撰设定集」。

**自撰剧情开关**：默认关闭，此时模型只能演绎原作设定，写的都是当月即兴的细节。打开后，模型可以基于原作设定自行发明人物、地点、组织与伏线，并把需要长期记住的部分提交为设定集，之后每回合都会回传给它，以保持前后一致。这些设定只随存档保存，不会写进游戏本体的任何内容文件，也不会影响其它存档；在游戏内「线索」标签页可以看到它们。设定集最多保留 24 条，超出后最早的会被挤掉。

**调用额度**：本作只对接 DeepSeek，聊天与余额都走官方接口。填入 API Key 后，可以随时点「刷新余额」向 DeepSeek 查询账户余额（含赠送与充值两部分）；每次推演结束后也会自动刷新一次。账户余额不足时 DeepSeek 会拒绝调用，游戏检测到这一点会停止推演并回退到本地引擎。

界面同时显示「本机估算已用」——按 token 用量与单价换算出来的金额，用于交叉核对。DeepSeek 的输入价区分缓存命中与未命中，两者差价很大，所以单价分成三栏（命中输入、未命中输入、输出），默认值是官方公布的人民币价，官方调价后请自行更新。另有可选的「本机硬上限」：填 0 表示不限额，填了之后本机估算花费达到该数额就会停止调用。

## 第二十九章之附 · 三种行动通道

行动分成三条互不重叠的通道，花钱的方式完全不同：

| 通道 | 怎么发起 | 谁来结算 | 花不花 AI 额度 |
| --- | --- | --- | --- |
| 预设指令 | 点场景面板上的按钮 | 本地引擎，按三档概率抽结果 | 不花 |
| 自由行动 | 在「自由行动」里自己写 | 模型实时推演 | 花一次调用 |
| 世界动态 | 推进一个月 | 本月是「AI 剧情月」才用模型，否则用本地文本池 | 只在 AI 剧情月花 |

**AI 剧情月**：只有当你在某个月用过自由行动，这个月才算 AI 剧情月。全程只点预设指令的月份，一次调用都不会产生——你可以完全不接 API 玩完整段人生。

**预设指令的结算**：每条指令都有三档结果。大概率是日复一日的常态，中概率是值得一说的转折，小概率是罕见时刻（可能是一次意外的领悟，也可能是一场惨败）。收益随难度缩放，但惩罚不缩水——高难度下的失败就是失败。战斗类指令额外吃已学招式的威力：招式越全，越不容易翻车。

**同一颗按钮，不同的戏。** 三档结果都可以挂上剧情条件：条件不成立的那一档根本不在这次抽取里。
于是同一条「和家里坐下来谈一次」，在没经历过转移事件的人生里只是闲谈，在转移之后会谈到那一年各自落在了哪儿。
指令也掀得开特殊事件——「你的行动」里某些档的结果会当场把一件抉择事件摆到你面前，
例如道场里求来的一场真刀真枪的较量、书库最里层翻出的那一页纸。这类事件在池子里只发生一次，
它不进随机事件池：不是世界找上你，是你自己走到了那一步。

**场景**：共 13 处，从家中、村镇集市、冒险者公会，到魔法大学、剑之道场、王都贵族圈、教会、迷宫、暗巷、旅途、战场、佣兵营地与书库。系统按你的所在地、出身与阶级自动定位到最可能身处的场景，你也可以随时切换到任何一处。每个场景配自己的指令表，按「战斗 / 修炼 / 学术 / 冒险 / 谋生 / 社交 / 探索 / 隐秘 / 信仰 / 家庭 / 休养」归类。

## 第二十九章之附二 · 招式与流派

招式名与流派特性按原作设定整理，分「普通」与「高级」两档。

- **剑神流**：速度与一击必杀，主打先手，一击不中则拉开再打。腕落是实用的一手；无音之太刀是上级技，挥斩无声；光之太刀是奥义，把全部斗气灌进一次挥斩，掌握它才有资格自称剑圣；光返是专门用来对付光之太刀的反击技。
- **水神流**：受け流し与反击，专守防卫，取「后的先」。流既是入门技，也是最高奥义之一。初代水神留下五道奥义，习得三道者可称水神；当世水神蕾伊达·莉亚以两道奥义组合出第六道「剥奪剣界」。
- **北神流**：不拘定式的实战流派，接近兵法。战场急救让你断了手指也能继续握剑；奇拔派主张动用一切道具、魔术与装备取胜。
- **斗气**：以体内魔力覆盖全身，提升力量、速度、反射与耐久，并可强化武器。能缠绕斗气，是上级剑士的门槛。
- **魔术**：按系统与阶级排列。火球弾、水弾、水蒸、水滝、土槍、衝撃波等初级魔术；水砲、氷霜撃、氷結領域、火断、極炎火弾等中级与上级魔术；治癒分ヒーリング、エクスヒーリング、シャインヒーリング三级，神撃魔术能伤到没有实体的东西。
- **混成与秘传**：把两系混起来是这个世界最实用的一条路——泥沼压住行动，岩砲弾高速射出，フロストノヴァ冻住地表，濃霧遮蔽视线。乱魔专门破坏别人正在发动的术式；無詠唱施法让魔术变成身体的一部分；結界魔术划出被隔开的一片；前龍門・後龍門与甲龍手刀『一断』只有甲龙王本人能教；時間魔术是已经失传的门类。

**怎么学**：普通招式靠长期练习与积累，在修炼类指令的小概率结果里领悟，也可能由名师点拨。高级招式只能由**特殊事件**或**强大角色亲自授予**——剑神流奥义要剑神级人物亲传，无咏唱施法要有人当面示范，甲龙王的手刀只有甲龙王能教。练得再勤也不会凭空练出高级招式。

已学招式在「技能」标签页里按流派归类显示，每条都标注战力权重；战斗类指令会把权重之和换算成有利偏置。

## 第二十九章之附三 · 关系网与角色对话

「关系」标签页是一张关系网：你在中心，每个人按关系性质分布四周。

- **关系性质**分血亲、师门、挚友、同僚、恋情、宿敌、熟人七类，由身份推定，决定节点与连线的颜色。
- **好感**决定节点大小与连线粗细，1 到 5 星。
- **年龄**：每个人都有一个出生年份，年龄随年份一年年长，节点与名录上都看得到。原作考据里写明生年的（洛琪希 373 年生、扎诺巴 397 年生、诺伦与爱夏 413 年生、露西 423 年、菈菈 427 年、亚尔斯 428 年、齐格哈鲁特 429 年、莉莉与克莉丝汀娜 431 年）是准的；其余人按身份推定，显示成「约 N 岁」。
- **看人**：点节点或点名录里的卡片，会把这个人的底细展开在右侧看板——身份、年龄、结识经过、好感、原作考据、你们之间的旧事。要开口说话，按看板里的「与他说话」。
- **地点**：每个人都在某一处。你在哪儿认识他，他就在哪儿；关系条目上写着「就在此地」「与你随行」，或者「人在布耶纳村」。最后一种意味着此刻见不着——说话与互动全部灰掉，按钮上写明原因；他也再不会主动来找你。想再见到他们，只能回到那边去。配偶、子女与旅伴这类跟你一起走的人，走到哪儿都能开口。
- **带谁走**：看板上有一个开关，可以把一个人带上路，也可以让他留下。见 4.1 节。

好感达到 **3 星以上**的人可以交谈。由「与他说话」打开对话窗，你一句、对方一句，随时可以结束。对话由模型按这个人的身份、年龄、信仰与时代来扮演：平民不会谈论宫廷政治，神职人员会说教，允许沉默、反问、拒绝回答；秘密只在真正被逼到墙角时才透露，而且往往只透露一半。

**结束对话时会结算**：模型通读整段交谈，判断它在现实里留下了什么。多数闲聊什么都不改变；说了伤人的话会掉好感，谈成了事会有收益，被追问出秘密就该有后果。一次对话占用本月一次行动。

## 第二十九章之附五 · 条件指令

预设指令可以带执行条件。条件不满足时按钮显示为不可执行，并把缺什么写在按钮上；引擎在结算时也会再拦一次，绕过界面也执行不了。

**条件可以写**：年龄下限、属性下限（魔力／剑术造诣／智力／魅力／信仰／财富／声望／密谋／健康）、剑术阶级、魔术阶级、冒险者等级、出身、所在地、剑术流派、信仰、政治倾向、已学招式、某段关系的好感下限；另有一组硬性禁止（出身／所在地／流派／信仰／立场）。

**这样做出来的差别，举例**：

| 指令 | 条件 | 说明 |
| --- | --- | --- |
| 以剑神流奥义结束这一战 | 剑神流 + 剑术圣级以上 | 不是剑神流的人拿不到这一手 |

## 第二十九章之附六 · 文风规范

游戏里所有文字——预设指令的结果、抉择事件、世界动态、AI 生成的剧本与角色对话——都按同一份文风规范写。它来自对原作行文的归纳：**外层冷叙述，内层不加引号的独白**，句子短，情绪落在动作和物件上。

1. **双层结构**：外面是冷静的客观叙述，里面是短的内心独白，不加引号直接嵌进去，常带自嘲或吐槽。「他把刀收了回去，动作像在嫌麻烦。……这算什么回答。」
2. **句法**：短句为主，长短交替，一段一到三句。善用「……」与「——」。不用长定语从句，不堆四字成语。
3. **情绪不直说**，写身体和动作。「你很难过」改成「你把碗放下，发现手在抖」。
4. **具体到物件、数目、气味、声音、钱、伤口**。日常写得琐碎才可信。
5. **死亡、暴力、失败、背叛直接写结果**，不抒情、不铺垫悲壮、不解释意义。转折来得突然。
6. **人物说话带身份**：平民谈收成与价钱，商人先谈价，贵族谈人脉与名声，神职人员说教，冒险者说话直接，斯佩路德族寡言而重荣耀，人神温和体贴且从不提代价。台词用「」包裹，旁白不加引号。
7. **世界不围着你转**：消息多是传闻，可能不准，可能被人有意放出来；你做的大多数事没人记得；努力未必有回报，好事都有代价。
8. **不要写**：空洞抒情、「命运的齿轮开始转动」式的旁白、网络流行语、把世界写成玩家的附属、给主角光环、无代价的收益。
9. **母题**是「这一世要认真活」，半途而废才是真正的失败；悔恨可以变成力量；选择比出身重要。它从情节里渗出来，不写成说教。

**叙事走向**：大概率档是日复一日的常态，中概率档是一件值得记住的小事（有得有失），小概率档是罕见时刻（可能是意外的领悟，也可能是真实的损失，不写成逆袭）。世界动态以安静为底色，真出了大事也只用一两句带过。

这份规范写在 `src/engine/ai.ts` 的 `STYLE_DOC` 里，由世界推演、自由行动、终章与角色对话四类提示词共用；固定剧本（`src/data/scenes.ts`、`src/engine/events.ts`、`src/data/canonEvents.ts`）与本地文本池（`src/engine/world.ts`）的人工文本按同一口径写。

## 第三十三章 · 保护协议

| 协议 | 内容 |
| --- | --- |
| 现实性保护 | 系统必须避免无限刷金币、粮食、军队、好感、圣物、头衔、领地、魔术、血脉。魔术必须有代价。血脉必须有风险。 |
| 规则漏洞保护 | 必须防止低阶技能无限叠加、某药物无限复活、时间类能力无限回溯、血脉无限觉醒、诅咒无限转移、契约无限签订。 |
| 世界信息保护 | 玩家不能自动知道谁是密探、圣物在谁手中、谁有血脉、谁被诅咒、谁是人神使徒、谁是龙神同伴。必须通过调查、推理、社交、观察、学习来获取信息。 |
| 防过度热闹 | 禁止每个月都有战争、圣物、转移事件、王位更替、拉普拉斯复活、人神使徒出动、龙神轮回。六面世界也必须拥有大量普通生活。 |
| 防主角光环 | 玩家没有默认贵族血统、圣物、预言、王位继承权、魔法天赋、龙族血脉、人神使徒身份。除非玩家真正通过世界中的行动获得。 |
| 防数值刷子 | 禁止站在村口砍 1000 只魔物升级。真正成长来自新环境、新问题、新理解、新技能、新情感。 |
| 时间线保护 | 玩家不能改变不可改变的历史锚点。保罗会死。洛琪希会死。菲托亚领转移事件会发生。拉普拉斯会复活。但玩家可以改变死亡的具体方式、转移事件中幸存者的命运、拉普拉斯复活后的具体行动路径。 |

**魔术规则保护**：

- 不能凭空变出食物。
- 不能复活死者。
- 不能无限使用时间魔术。
- 不能在没有魔力的情况下施法。
- 不能同时使用多个魔术体系而不付出代价。

## 第三十七章 · 冒险的真正意义

> 冒险不是「打怪刷装备」。冒险是：**信息 ＋ 风险 ＋ 世界发现 ＋ 情感代价**。

- 玩家可能进入一座废弃迷宫，什么宝物都没有，但发现一段改变家族命运的记录。
- 玩家可能追踪一只魔物，发现魔物是自己失踪多年的亲人。
- 玩家可能找到一个古代遗物，不知道如何处置，最终选择保护它或摧毁它。
- 玩家可能与人神签订契约，获得力量，但失去选择的自由。
- 玩家可能被诅咒，必须在限定时间内找到解除方法，最终发现诅咒源头是自己祖先的罪孽。

## 第四十七章 · AI 运行身份

## 第四十八章 · 终极原则

| 原则 | 内容 |
| --- | --- |
| 【自由】 | 玩家可以尝试任何合理行为，系统计算后果不限制行动。 |
| 【权力】 | 权力拥有规律、成本与限制。没有免费的贵族头衔。 |
| 【社会】 | 出身、种族与信仰真实存在。偏见、歧视、合作与冲突都是六面世界的真实部分。 |
| 【命运】 | 血脉与转生拥有力量，但没有绝对必然。选择比出身更重要。 |
| 【信仰】 | 魔术公会、米里斯教团、剑之圣地、冒险者公会彼此制衡。 |
| 【经济】 | 金币、领地、迷宫遗物决定战争与和平。 |
| 【生态】 | 魔物、迷宫、种族冲突影响文明。 |
| 【文明】 | 六面世界会发展、分裂、衰落或复兴。不是静态背景。 |
| 【未知】 | 六面世界存在玩家无法理解也无法预测的秘密。系统不会提前告知。 |
| 【时间】 | 六面世界不会停下来等待玩家。 |
| 【人格】 | NPC 拥有独立的人生、目标、情感。他们不是你的附属品。 |
| 【历史】 | 玩家可以改变历史——但需要足够分量、时间和影响力。 |
| 【死亡】 | 玩家可能死去。死亡默认真实且不可逆。 |
| 【传承】 | 玩家的故事可以延续到下一代，也可以在这一代终结。 |
| 【人神】 | 人神存在，但不万能。人神只能诱导，无法强制。 |
| 【龙神】 | 龙神存在，但只在轮回中。奥尔斯帝德有自己要守护的东西。 |
| 【魔术】 | 魔术存在，但不泛滥。高级魔术有代价。 |
| 【血脉】 | 血脉是命运，但不是宿命。你可以选择如何面对它。 |
| 【诅咒】 | 诅咒是真实的。解除它需要代价，几乎不可逆。 |
| 【契约】 | 契约必须遵守。违约的后果比履行更可怕。 |
| 【异类】 | 异类不是怪物。他们有自己的人生、逻辑、情感。你可以选择如何对待他们。 |
| 【冒险】 | 冒险不是打怪刷装备。冒险是信息、风险、发现、情感。 |
| 【情感】 | 每个人物都会爱、会恨、会嫉妒、会牺牲、会背叛、会后悔、会怀念。情感不是数值，是故事。 |
| 【绝望】 | 六面世界在衰亡。人神在暗处微笑。拉普拉斯会复活。你很可能只是无数死者之一。但你可以选择如何活着。 |

### 49.2 成就

**【成就提示】**

> 当人神在六面世界中心低语，龙神在轮回中孤独前行，拉普拉斯在封印中等待复活，你能否成为那个例外。

**触发条件**：帮助奥尔斯帝德击败人神，或在人神与龙神的棋局中走出第三条路，或在拉普拉斯复活后阻止第二次拉普拉斯战役。**此成就几乎不可能。系统不会阻止你尝试，但六面世界不会为你让路。**

**【隐藏成就】**

| 成就 | 条件 |
| --- | --- |
| 当死亡不是终点 | 你的故事被下一代继续，家族延续超过三代。 |
| 当记忆成为传说 | 你死后一百年，你的故事仍在流传。 |
| 当选择成为命运 | 你在关键时刻做出选择，改变了六面世界的走向。 |
| 当悔恨成为救赎 | 你一生背负的悔恨，最终成为拯救他人的力量。 |
| 当平凡成为伟大 | 你一生没有成为七大列强，但你救了一百个普通人。 |

> 请提交你的选择。你的第一把剑、第一根魔杖、第一个魔术、第一个朋友、第一个敌人、第一次失去、第一次原谅——即将穿过这片无职转生的六面世界。
>
> **黑暗中有东西在低语。迷宫深处有东西在等待。人神的棋盘上有一颗棋子空着。**
