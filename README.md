# 无职转生：人生模拟器 · 六面世界

基于《无职转生～到了异世界就拿出真本事～》世界观的文字人生模拟器。

你创建一个人物，然后以「月」为单位推进他的一生。世界照常运转，不会因为你出生而停下：
原作里那些人在他们该出现的时间、该在的地方出现，成婚、生子、死去，都在你之外照原样发生。
你能改变的，只是你自己站在哪里、护住了谁。

React 19 + TypeScript + Vite 构建，Electron 打包为 Windows 免安装版。

## 特性

### 人物

- **自由开局**：出身、时代、天赋、信仰、政治倾向、目标与情感基调都可自定义；也可以直接扮演原作模式里的鲁迪乌斯。
- **原作人物名录**：106 位有名有姓的原作人物，各自的所属、身份、可亲授的招式与考据备注。
  163 条人物之间的人际关系，在关系网里以金色虚线相连。
- **严格的时间与地点**：每个人的登场都有两道门槛。**地点**只看你此刻站在哪儿——
  选了「拉诺亚魔法大学」不代表人已经住在夏利亚，七岁的鲁迪乌斯在布耶纳村的院子里见不到大学与剑之圣地那一整批人；
  罗亚与布耶纳村虽同属菲托亚领，也是两个地方。**时间**是硬门槛，年份没到，条件再合适也不会出现。
- **年龄**：每个人都有一个出生年份，年龄随年份一年年长。考据里写明生年的准确，
  其余按身份推定，显示成「约 N 岁」。
- **关系网**：点一个人看他的底细——身份、年龄、结识经过、好感、原作考据、原作关系、秘密、他记得的旧事。
  好感 1 到 5 星，关系性质分血亲、师门、挚友、同僚、恋情、宿敌、熟人七类。
- **所在地与同行**：你在哪儿认识一个人，他就在哪儿。你搬走了，他还留在原地，当面的事全部做不了，
  他也不会再来找你——想见他们，得走回去。**带谁走由你定**：关系网里可以把一个人带上路，
  往后跟你走到哪儿都还能开口；配偶与子女属于你的家，不用交代。

### 世界

- **所在地与迁居**：12 个去处，各有各的行动、各自的场合、各自等在那里的原作事件。
  迁居要走一整月，门槛不到走不过去。
- **剧情门槛**：场景与指令按年份、剧情标记、经历事件、技能、属性、关系、所在地判断该不该出现。
  门没开的指令根本不出现，条件差一点的按钮灰掉并写明缺什么。
- **剧情分支**：同一条指令按处境开出不同的戏。没经历过转移事件的人生里「和家里谈一次」只是闲谈，
  转移之后会谈到那年各自落在了哪儿。某些档的结果还会把一件特殊事件掀到台面上，
  例如道场里求来的一场真刀真枪的较量、书库最里层翻出的那一页纸。
- **抉择事件**：通用事件、原作时间线事件（14 件）、以及 106 位原作人物各自的剧本钩子，
  再加上只能由指令翻开的特殊事件。另有 6 件原作模式专属的主线节点（转移事件、转移迷宫救母、魔石病、
  与龙神交手、阿斯拉王位争夺、与基斯的最终决战）。锚点有前提——保罗之死要你真的下到迷宫最底层，
  洛琪希之死要你做过人神使徒。
- **生育与传承**：玩家成婚、生育、看着孩子长大；原作写明年份的夫妻按时间线成婚添丁
  （鲁迪乌斯与希露菲叶特、洛琪希、艾莉丝三条线，以及格雷拉特家的下一代）。

### 文字与系统

- **折叠纪事**：一次只展开一条，默认停在最新一条。滚轮逐条翻阅，或拖动时间轴按时间跳跃。
- **年鉴**：跨年时封存当年大事，可在「月度 / 年度」之间切换回头看。
- **长期记忆**：常来往的人会记住发生过的事。他说过的话、你对他做过的事，都留在他身上。
- **成就与终章**：人生结束时生成传记式终章，并结算解锁的成就。
- **难度**：安逸 / 标准 / 残酷 / 地狱四档，可随时切换。改变寿命、收入、健康衰减、事件频率与抉择代价；
  已发生的事不会改写。
- **存档**：一个自动存档 + 三个手动存档，支持导出为文本或链接分享。

### AI 推演（可选）

不配密钥也完全能玩：预设指令、事件、关系互动全部由本地引擎即时结算，不产生任何调用。

配上 DeepSeek 的 API Key 后，可以额外获得三件事：

- **世界推演**：你在自由行动里写下想做的事，交给模型推演世界动态，并把结果交回引擎落账。
- **角色对话**：按那个人的身份、年龄、信仰与时代来扮演 —— 平民不谈宫廷政治，神职人员会说教，
  允许沉默、反问、拒绝回答；秘密只在被逼到墙角时才透露，而且往往只透露一半。
  对话结束时模型通读整段交谈，判断它在现实里留下了什么。
- **终章改写**：人死之后，由模型重写一遍传记式终章。

密钥只存在你本机的 `localStorage`，不进存档、不进分享链接。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run lint       # oxlint
npm run electron:dev   # 构建后用 Electron 启动桌面版
npm run dist:win   # 打包 Windows 免安装版
```

`npm run dist:win` 会先执行 `vite build`，然后下载官方 Electron 的 `win32-x64` 运行时，产出：

- `release/无职转生人生模拟器-win32-x64/` —— 免安装目录
- `release/无职转生人生模拟器-<版本>-win32-x64.zip` —— 分发的压缩包

运行时下载缓存在 `.cache/`，重复打包不重新下载。打包脚本不依赖 Windows 或 wine，可在任意平台产出。
桌面版通过自定义 `app://` 协议加载本地资源，因此 ES 模块、`localStorage` 与 `fetch` 都能正常工作。

## 存档与导入接口

浏览器控制台（或桌面版开发者工具）中可直接调用：

```js
MushokuLifeSim.help()              // 查看全部接口说明
MushokuLifeSim.import(saveOrUrl)   // 导入：JSON 文本 / 对象 / base64 / 完整链接
MushokuLifeSim.export()            // 导出当前人生为 JSON 文本
MushokuLifeSim.state()             // 读取当前游戏状态对象
MushokuLifeSim.loadSlot('1')       // 读取槽位：auto / 1 / 2 / 3
MushokuLifeSim.shareUrl()          // 生成一份可分享的导入链接
```

URL 导入：在地址后追加 `?save=<base64 或 JSON>`，打开页面即会载入这份人生。

## 设计上的几条硬规矩

这些是刻意的取舍，改代码前值得先看一眼：

- **数值只有一个夹取点**：所有数值改动都要经过 `engine/world.ts` 的 `applyEffects`，
  普通行动、世界动态与抉择事件各有各的边界（见 `LIMITS` / `EVENT_LIMITS`）。
  AI 给的数字同样走这里，模型不能直接改坏存档。
- **AI 自撰的内容只进存档**：AI 造出来的场景与指令存在 `GameState.customScenes` 里，
  按标签去重、有数量上限，不写进 `src/data` 下的任何文件。所以同一段设定只在那一份存档里成立。
- **预设指令不花额度**：本地引擎即时结算，不产生任何 API 调用。
- **AI 额度用尽强制回退本地引擎**，不允许超额调用。
- **AI 的生老病死判定直接执行**，引擎不做二次否决——核心剧情判断权交给模型。
- **密钥只在本机**：DeepSeek 的 API Key 只存 `localStorage`，不进存档、不进分享链接。
